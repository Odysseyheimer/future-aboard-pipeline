# Pocket Tutor — Japanese layer pipeline

Source for the Japanese (日本語 + furigana + romaji) layer of the Pocket Tutor study app.
The app itself is published from the **public** repo `Odysseyheimer/future-aboard` (GitHub Pages).
This repo is **private** and holds the generation pipeline, the translation memory and the app sources.

> Privacy rule: never commit or push anything that contains the owner's real name, email, local Windows
> paths or the app passcode. Commit as `Odysseyheimer <nopskunggmaer24@gmail.com>`.

## Layout

| Path | What |
|---|---|
| `scripts/pedagogy/ja/` | the pipeline (Python 3.11+, plus Node for the parity test) |
| `scripts/pedagogy/ja/tm/<deck>.jsonl` | **translation memory — the source of truth.** Append-only; stage precedence human > verify > review > author |
| `scripts/pedagogy/ja/gold/tatoeba300.json` | human furigana gold set for reading accuracy |
| `scripts/pedagogy/assemble_app.py` | builds the single-file `output/app.html` from `output/ptmods/` and inlines `data/ja/index.json` as `JA_INDEX` |
| `output/ptmods/` | app modules (`ja.js`, `ja.css` are the Japanese layer; `sw.js` is the service worker) |
| `output/data/*.json` | the decks the units are enumerated from (same files as `data/` in future-aboard) |
| `output/data/ja/` | built sidecars (generated by `ja_build.py`, not committed) |

## Setup

```bash
python -m pip install -r requirements.txt
# reading witness for word glosses (QA only, ~47 MB, not committed):
#   download JmdictFurigana.json from https://github.com/Doublevil/JmdictFurigana/releases
#   into scripts/pedagogy/ja/ref/JmdictFurigana.json
cd scripts/pedagogy/ja
python -X utf8 reading_ja.py        # rebuilds the derived.jsonl cache from the TM (takes a few minutes)
python -X utf8 validate_ja.py
python -X utf8 ja_build.py --pilot  # sidecars + index + parity test
```

## Per-phase flow

`export_ja.py --phase PX --delta` (writes all waves; ≤45 chunks and <400 KB each) → run waves **one at a time**
(or chain them with a parent script using `workflow({scriptPath})`) → `harvest_ja.py <runDir>` after each →
`reading_ja.py` (aligns the author's hiragana `yo`; fugashi/unidic-lite, SudachiPy, numerals.py and JmdictFurigana
are witnesses; flags go to verify) → `export_verify.py --round N` → `validate_ja.py` (0 hard fails) →
back-translation (`export_bt.py`) → `export_fix.py` for drift → `ja_build.py` → deploy.

## Workflow tool gotchas
- Scripts over **512 KB are rejected** — every exporter splits by size.
- `args` are not passed to scripts here — everything is baked into the generated `.wf.js`.
- Write `.wf.js` files LF-only with no control characters (the approval dialog rejects `\r`).
- Session/weekly limits kill agents mid-run: harvest what finished, then `resumeFromRunId` the same run
  (harvest is idempotent by `(runId/chunk/stage, lid)`).
